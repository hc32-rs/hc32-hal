# 系列与外设支持情况

| 符号 | 状态 | 填写条件 |
| --- | --- | --- |
| ✅ | 已测试 | 对应系列的板上例程实测通过，链接到记录了芯片、板卡、实例、测试功能与结果的例程或测试记录。 |
| 🧪 | 已编写待测试 | 驱动和对应例程均已为目标芯片构建，待上板验证。 |
| 🧩 | 已编写缺例程 | 已为该系列实现驱动，缺少演示该功能的板级例程。 |
| ⬜ | 未编写 | 系列有此外设，HAL 驱动尚未实现。 |
| ➖ | 无此外设 | 按当前系列外设清单，该系列没有此行对应的外设类型。 |

行名沿用各数据仓库 `data/csv/register_versions.csv` 的 `kind`，列为系列。填写时同时核对同目录的 `peripherals.csv` 外设实例清单和寄存器版本映射。若芯片手册与清单有出入，以对应型号的手册为准。单元格描述已覆盖的功能；同系列存在多种实例、模式或封装时，请在链接记录中注明覆盖范围。其他系列即使复用同一驱动，也须分别记录板测状态。

HC32F175 已由数据工具暂停支持，未纳入 LL 表。
